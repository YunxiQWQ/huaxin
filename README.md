# 画芯 Huaxin · 本地优先的报刊画册排版

[在线使用](https://tool.heyunxi.top/huaxin/) · [介绍与使用指南](https://tool.heyunxi.top/huaxin/guide) · [GitHub](https://github.com/YunxiQWQ/huaxin) · [MIT License](LICENSE)

在浏览器中制作报纸、校刊、电子画册和图文手册的多页排版工具。编辑、排版、预览、自动保存和导出全部在用户浏览器内完成；网站只是静态站点，提供程序、模板和字体。

完整流程：选择模板或空白新建 → 导入本机图片 → 多页排版 → 本机自动保存（IndexedDB）→ 本地预览 → 导出 PDF / PNG / JPEG 或工程文件（.bxproj）。

## 启动与构建

需要 Node.js 22.13+ 与 pnpm 10.34.3（见 `package.json` 和 `.mise.toml`）。可先运行 `corepack enable` 使用锁定的 pnpm，或在下列命令中将 `pnpm` 替换为 `corepack pnpm`。

```bash
corepack pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1   # http://localhost:8443/
pnpm typecheck      # TypeScript 检查
pnpm build          # 生成静态站点到 dist/，可部署到任意静态托管
pnpm build:site     # 为 /huaxin/ 子路径构建（Vercel 部署使用）
pnpm serve:dist     # 本地以静态方式预览 dist/（含 Service Worker，用于离线测试）
pnpm check:secrets  # 检查待入库文本中的常见凭据格式
pnpm fonts <源字体目录> [字面ID]   # 生成站点字体；可只更新一个字面（见下文“字体”）
```

部署：把 `dist/` 整个目录放到静态服务器即可，无需后端、数据库或账号。`index.html` 与 `sw.js` 建议设置为不缓存（`Cache-Control: no-cache`），其余带哈希的文件可长期缓存。

线上入口为 `https://tool.heyunxi.top/huaxin/`，介绍页为 `/huaxin/guide`。仓库的 `vercel.json` 使用锁定的 pnpm 构建子路径版本；工具箱站点将 `/huaxin` 与其子路径转发到画芯的独立 Vercel 项目。资源与 Service Worker 均限定在 `/huaxin/`，本机草稿仍只属于当前浏览器和网站地址。


## 关键设计

**一份排版数据，三处使用。** `layout/textLayout.ts` 用 Canvas 测量每个字符的字宽，按中文规则断行，得到每一行的文字、位置、基线和字间距（含两端对齐的增量）。编辑器 DOM、PNG/JPEG 导出（Canvas）和 PDF 导出都从同一份显示列表（`render/displayList.ts`）绘制，因此换行、分栏、位置与图片裁切一致。DOM 中关闭了字距调整、连字和标点挤压，避免浏览器自行改变字宽。

**画布原位编辑。** 双击文本框，或在右侧点击“原位编辑”，直接在版面原位置输入。文字沿用原来的颜色、字号、对齐与分栏，背景保持可见，输入后立即重新排版；不再弹出白底输入框。点击其他位置、Esc 或 Ctrl+Enter 结束编辑。中文组字保留浏览器输入法状态，确认后才写入文档；支持选取、复制粘贴、方向键与撤销重做。超出文本框的稿件仍完整保留，可通过右侧稿件内容查看。

**中文排版。** 汉字逐字可断，西文单词与数字整体不断；行首禁用（，。、；：？！”）》等）与行尾禁用（“（《等）字符按推入/推出处理：闭合标点略超出时整行微收紧容纳（推入），否则前移一字（推出），再两端对齐；支持行距、字距、段前段后、首行缩进、多栏连续流动、栏间分隔线、垂直对齐，排不下时在文本框右下角显示红色溢出标记，并在“检查”面板与导出前检查中列出、可定位。“平衡分栏”按钮用二分法求出各栏等高的最小框高。

**PDF。** 在 Web Worker 中用 pdf-lib 生成：页面尺寸为作品物理尺寸（毫米换算为点），文字以真实文字输出（逐行 `Tj`，`Tc` 实现字距与两端对齐，斜体用文字矩阵倾斜，缺粗体字重时用描边模拟加粗），可选择、搜索、复制；字体先用 HarfBuzz（WebAssembly）按实际用字子集化后嵌入（pdf-lib 自带的 TrueType 子集化会丢失部分中文字形，已验证并替换）；图片使用原图并按图框裁切（剪切路径），不做整页截图。

**本机保存。** IndexedDB 中作品元数据与每一页分开存储；编辑后约 0.9 秒合并保存（最长 5 秒），只写入发生变化的页面。图片按 SHA-256 内容寻址只存一份，作品、副本和历史版本共用。每次写入检查修订号，其他标签页已写入更新内容时不会覆盖，而是暂停保存并让用户“另存为新作品”或“载入最新内容”（本页内容先存为历史版本）；无本地修改的标签页会自动跟随。

**历史版本。** 编辑期间约每 5 分钟自动生成一个版本，可手动保存版本（Ctrl+S 也会生成），每个作品保留最近 12 个；恢复前自动保留当前内容为一个版本，恢复本身也可撤销。

**离开提醒。** 当前作品自上次“下载工程”（或打开）以来有修改时，关闭或刷新页面会请求浏览器显示离开提醒；下载工程成功或撤销回到该保存点后提醒自动解除（实际是否弹出由浏览器策略决定，通常需要页面有过用户交互）。

**工程文件 .bxproj。** ZIP 包：`manifest.json`（格式标识、格式版本、资源清单、字体名称）、`document.json`（页面结构、可编辑文字、元素属性）、`assets/`（使用到的图片原图）、`README.txt`。导入时：校验格式与版本（更新版本创建的工程会提示升级）、按白名单逐字段重建数据（未知字段丢弃、数值钳制、颜色/ID 正则校验）、按文件头识别图片类型（拒绝 SVG 等可执行内容）、核对 SHA-256、限制解压体积；导入总是建立新作品，失败不影响当前作品。文本只以纯文本渲染，不使用 innerHTML。

**离线。** 生产构建注册 Service Worker：安装时预缓存程序、模板与 HarfBuzz 组件，字体在首次使用时缓存（工作台可“一键缓存全部字体”）。加载过一次后，断网仍可打开网站、继续编辑、本机保存并导出 PDF / 图片 / 工程文件。

**隐私。** 无账号、无后端、无统计脚本、无第三方 CDN。用户导入的文字、图片和工程文件不会上传；Service Worker 只处理同源 GET 请求。

霞鹜文楷使用 v1.530 的官方 Regular 原版（47,336 字形，约 24.73 MiB），保留完整字体、内部名称和相应许可证，按需加载并缓存；未重新分发带保留名称的自制字体子集。`manifest-v1.530.json` 记录版本、SHA-256 与实际覆盖范围。其余字体由 `scripts/build-fonts.mjs` 固定静态字重，并子集化为《通用规范汉字表》8105 字 + GB2312 + 常用标点符号（约 1.15 万字符），每个文件 3–6 MB。站酷小薇和马善政楷书缺少约 1482 个通用规范字，所用字体缺字时检查面板会提示。工程文件只记录字体名称，不打包字体文件。

单独更新文楷：下载官方 `LXGWWenKai-Regular.ttf`，在源目录中存为 `LXGWWenKai.ttf`，同时放入对应版本的 `OFL-lxgw.txt`，运行 `pnpm fonts <源目录> lxgw-wenkai-400`。其他字面和旧工程的 `kai` 字体引用保持兼容。

**使用本机字体：** 选中文本框，在右侧字体区域点击“使用本机字体”并允许浏览器访问。下拉列表先显示网站字体，中间是一条横线，下方是本机字体（同一家族的常规、粗体与特粗按字重选择）。此功能使用桌面 Chrome / Edge 的 Local Font Access API，需要 HTTPS 或 localhost；不支持的浏览器仍可使用网站字体。

只在选中某款字体后读取其字面数据，保留在当前标签页内存中，支持编辑、预览、PNG/JPEG 与 PDF 导出；Windows TTC 合集会提取正确的字面。不会上传、写入草稿数据库或打包本机字体文件。草稿与工程只保存稳定的字体名称引用：已授权时刷新可自动恢复，未授权或换设备缺字体时会提示，保留原字体选择并暂用思源宋体。PDF 遵守字体的 OS/2 嵌入限制；禁止嵌入的字体需替换，禁止子集化的字体整字面嵌入。字体自身的使用授权仍以其许可为准。

新字体和覆盖清单使用带版本号的文件名，避免命中旧版缓存，并保留已缓存的其他字体。开发服务器运行时执行 `pnpm e2e:fonts`；生产构建与 `pnpm serve:dist` 运行时执行 `pnpm e2e:font-cache`，验证旧缓存兼容和新版字体离线读取。

## 已知限制

- 文字样式以文本框为单位；需要不同样式时使用多个文本框（标题、导语、正文分框，这也是报刊常规做法）。
- 组合只有一层；多选时可移动、对齐、分布，但不能整体缩放。
- 部分网站字体为常用字子集（霞鹜文楷使用官方完整字库）；超出所选字体覆盖范围的字在编辑器中可能以系统字体显示，在 PDF 中会缺字，检查面板会列出缺字。没有粗体/斜体字面的字体使用模拟粗体与倾斜（编辑器与导出一致）。
- PDF 为 RGB，不含出血、裁切标记与 CMYK 输出。
- 撤销历史不跨刷新保存（作品内容与历史版本会保存）。离开提醒以本次打开或上次下载工程为基准。
- 自动备份属于当前浏览器与当前网站地址；清除浏览器数据会删除它们，长期保存请下载工程文件。浏览器可能在存储紧张时清理数据，程序会请求持久化存储，但最终由浏览器决定。
- 测试环境（无头 Chromium、Linux）中验证了 Chrome 内核；Edge 同为 Chromium 内核，未单独实测。

## 开源项目评估

- **yft-design、vue-fabric-editor**：Vue / Fabric.js 编辑器，可参考画布交互与模板操作。本项目采用 React，已有自定义中文文字布局及 PDF 管线，当前未集成这两个编辑器。
- **DesignCraft**：采用 Rust / WebAssembly 的独立出版排版项目，提供分栏、文本续排等能力。本项目没有集成其引擎，当前中文排版能力不以该项目的功能说明作为验证依据。
- **Paged.js**：面向 HTML 连续文档的 CSS 分页，PDF 依赖浏览器打印，适合书籍流式排版，不适合自由版式的多页报刊编辑器，未采用。
- 实际采用的库见 `THIRD_PARTY_NOTICES.md`（pdf-lib、@pdf-lib/fontkit、harfbuzzjs、fflate、idb、lucide-react 等），均为宽松许可。
