画芯 Huaxin

把文字与图像，编排成一份自己的报纸。

在桌面浏览器中制作报纸、校刊、电子画册与图文手册。从模板开始，也可以自由编排。编辑、预览、自动备份与导出都在本机完成，无需注册账号。

从一页到整本

01 / 编排

多页模板与中文分栏

使用报纸、校刊、画册与手册模板；调整页面、文字、图片和形状，设置栏数、行距、字距与段落缩进，检查文字溢出。

02 / 字体

网站字体与本机字体

内置思源宋体、思源黑体、霞鹜文楷等字体。桌面 Chrome / Edge 经授权后，可读取本机已安装字体并用于排版与导出。

03 / 保存

本机备份与成品导出

编辑内容自动保存在当前浏览器，定期保留本机历史版本。导出可选取文字的 PDF、PNG / JPEG 图片，或可继续编辑的工程文件。

开始制作

  1. 进入画芯，从模板中心选择版式，或创建空白作品。
  2. 选择文本框填写稿件，调整字体与分栏；从本机加入图片，按页面组织内容。
  3. 使用检查面板查看溢出、缺字和缺失图片，再通过本地预览确认排版。
  4. 导出 PDF 或图片用于阅读和打印，同时下载工程文件，留待下次继续编辑。

内容留在本机

网站提供程序、模板和字体。你的稿件、图片、工程与本机字体不会上传，也没有在线发布或分享托管功能。程序和所用资源缓存后，可继续离线编辑和导出。

自动备份属于当前浏览器与当前网站地址。清理浏览器数据会移除本机记录，长期保存或换设备时，请下载工程文件；工程不打包本机字体，其他设备需安装同名字体。
